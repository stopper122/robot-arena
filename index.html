Robot Arena Core Rush

Drive into the yellow cores to pick them up (you can carry 2). Shoot them into your team's goal: Red scores on the right, Blue scores on the left. Shot in = 3 points, pushed in = 1 point.

Press A on a controller to join (keyboard: Space or Enter). X changes drive style, B leaves. Press A again when you're ready. Shoot with R1 / R2 / L1 / L2.
How to hook up VEX V5 controllers
  1. Download robot_arena_bridge.py, open it in VEXcode V5 and download it to a V5 Brain (any slot). Run it.
  2. Plug the controller (paired to that brain) or the brain into this computer with USB.
  3. Click Connect V5 controller and pick the VEX port. If nothing happens after a few seconds, click it again and pick the other VEX port (the brain has two; the game needs the "User" one).
  4. One brain can run two players: the primary controller and a partner controller.
Needs Chrome or Edge (computer or Chromebook). Xbox-style USB/Bluetooth gamepads and the keyboard work too: Keyboard 1 = WASD + Space, Keyboard 2 = arrows + Enter. Esc during a match returns here, F toggles full screen.
